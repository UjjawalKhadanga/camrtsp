# camrtsp identity

The mark combines a camera lens, an open C, and an outgoing signal arrow.

- `mark.svg`: master vector mark; also used as the site favicon.
- `banner.svg`: editable 1280 × 640 GitHub README banner.
- `social.png`: raster social preview, rendered from the banner.
- Android uses the matching vector drawable at `apps/android/app/src/main/res/drawable/ic_brand.xml`.

Charcoal `#101310`, electric mint `#B7FF5B`, warm white `#F1F3E9`, muted sage `#A3AD9D`. Use Instrument Sans for headlines and body copy, IBM Plex Mono for technical labels. Keep the mark upright and preserve clear space around it.

Motion follows the product: orbiting signals, optical rotation, scanning frames, and a moving wireframe landscape. Honor reduced motion preferences. The playground is a simulation and must remain labeled as such.
